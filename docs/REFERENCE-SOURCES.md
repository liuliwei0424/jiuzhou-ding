# 参考图与形制参考资料记录（P2 · Day 0）

任务要求：准备 2–3 张参考图（司母戊鼎、二里头网格纹鼎），记录**图片来源和许可/使用条件**。

## 结论先行

本项目**没有把任何第三方图片加入仓库，也没有在任何模型上贴第三方图片**。原因有两条：

1. 博物馆官网图片多数只授予「浏览/非商业引用」权利，不明确授予「再分发到开源仓库 + 用于 3D 贴图」的权利。把它们提交进 `public/` 会造成许可风险。
2. 参数化建模只需要**形制信息**（比例、部件、纹饰位置），文字描述 + 公布尺寸已经足够，不需要复制像素。

因此参考图在本项目中的角色是**「查证用的外部链接」**，而非交付资产。下表记录每一条资料来源与使用条件，模型与此的对应关系写在 `ASSET-SOURCES.md`。

### 已核查并排除的来源

| 来源 | 结论 |
|---|---|
| 维基共享资源（Wikimedia Commons）上的后母戊鼎照片 | 多为 CC BY-SA 或「仅部分权利保留」，允许再分发但**需署名 + 相同方式共享**，一旦用于贴图会传染整个资产许可。为保持资产许可简洁（项目原创、随项目分发），不采用。 |
| 各类百科 / 自媒体转载图 | 无法确认原始权利人与授权状态，一律不用。 |

## 从参考到模型的映射（可审核）

| 参考特征 | 本模型对应 | 差异说明 |
|---|---|---|
| 三足承器（R1 四足方鼎 / R2 三足圆鼎） | 取 R2 的三足 | 圆鼎传统，符合「一鼎象征一州」的叙事需要 |
| 立耳、折沿 | `rim`（侈口 + 加厚口沿）、`ear-left/right`（扁平环耳、双足贴壁） | 耳更宽、更厚，便于低面数下辨识 |
| 柱足 | `leg-front-left` / `leg-front-right` / `leg-back`，微外撇 | 足比 R2 的「四棱锥状」更圆，取 R1 柱足的处理 |
| 腹部带状纹饰 | `decor-band`（雷纹带，贴图阴线） | R2 是网格纹，这里是**雷纹仿纹**，属艺术取舍 |
| 足上凸弦纹（R1） | 腹部两道弦纹（`band-578` / `band-648`） | 位置上移，为视觉上更接近「纹饰带分隔」 |
| 器壁极薄（R2 仅 1.5 mm） | 壁厚约 17–24 mm | **刻意加厚**：1.5 mm 在实时渲染里会穿模，且不符合本模型约 0.9 m 的体量比例 |
