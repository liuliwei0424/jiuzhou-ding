### 2.1 几何构成

| 部件 | 做法 | 备注 |

## 3. 纹理清单

| 文件模式 | 通道 | 色彩空间 | 生成方式 |
|---|---|---|---|
| `public/textures/ding-*-basecolor.png` | RGB(A) 基础色 | sRGB | 程序化：多尺度 fbm 噪声 + 竖向流挂 + 高度偏置（底部积锈） |
| `public/textures/ding-*-orm.png` | R=AO，G=Roughness，B=Metallic | Non-Color | 由同一组噪声推导，符合 glTF ORM 打包约定 |

- 锈色取值：孔雀石绿、浅绿锈、蓝铜矿蓝；青铜基色为偏暗的铜锡合金色。
- 纹样：`leiwen` 为嵌套方框构成的雷纹带，`inscription` 为随机短笔画。
- **明确声明**：雷纹与铭文都是**装饰性仿纹**，不对应任何具体器物的纹样单元，也不还原任何真实金文释文。纹样参数（网格密度、行数、笔画种子）见脚本内 `_leiwen_mask` / `_inscription_mask` / `PROVINCES`。
- 纹理尺寸：`ding-base` 1024²，LOD1 与九鼎 512²；全部可无损重生成（同种子结果一致）。

## 4. 艺术复原说明（须在页面与评审中可见）

1. 本项目展示的是**一件虚构的「九州鼎」示意器**，用于说明「一鼎象征一州」的观念，不是对九鼎的复原，也不是对某件出土铜鼎的复制。
2. 传说中「大禹收九牧之金，铸九鼎于荆山之下」出自《史记·封禅书》等文献，属**文献记载与传说**，迄今**没有**九鼎实物出土，也没有任何考古发现能证实其形制、尺寸、纹饰。
3. 形制取向（三足圆鼎、立耳、深腹、柱足、腹部带状纹饰）参照的是**商周青铜圆鼎的通行形制**，属于风格化取舍；具体比例由本项目参数化脚本给定，不来自任何一件器物的测量数据。
4. 九鼎之间的尺寸差、锈蚀差、纹饰行数差是**视觉区分手段**（帮助用户在地图上分辨），不代表任何历史差异。
5. 铭文为抽象笔画，**不构成文字**，不可释读，不承载任何史料内容。
6. 页面须始终可见「艺术复原示意，非考古还原」（README 已写入免责声明，P4 需在 UI 中保留）。

## 7. 复现方式

```sh
# 依赖：Blender 5.x（本机 5.2.2 LTS）
/Applications/Blender.app/Contents/MacOS/Blender -b -P scripts/build_ding.py -- --build
# 另出新预览图（Cycles，CPU，24 采样）
/Applications/Blender.app/Contents/MacOS/Blender -b -P scripts/build_ding.py -- --preview
```

产出：`public/models/*.glb`、`public/textures/*.png`、`data/assets/ding-manifest.json`、`docs/assets/previews/*.png`。
脚本不含随机性（固定 `seed`），任何人重跑得到一致结果，便于审核。
